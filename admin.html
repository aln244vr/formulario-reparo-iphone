🔑 Conectar para salvar

Você pode olhar e editar sem conectar, mas para salvar precisa de uma chave do GitHub. Só precisa fazer isso uma vez neste celular.

Como criar a chave (2 minutos)
  1. Abra github.com/settings/personal-access-tokens/new (com login na conta aln244vr).
  2. Token name: painel catalogo
  3. Expiration: escolha 1 year.
  4. Repository access: Only select repositories → formulario-reparo-iphone.
  5. Permissions → Repository permissions → Contents → Read and write.
  6. Toque em Generate token, copie o código (começa com github_pat_) e cole abaixo.

A chave fica guardada só neste aparelho. Não mande ela para ninguém.

📥 Receber do caixa

No Pedidos & caixa, toque em Preços → Enviar para o site. Depois cole aqui e toque em Salvar. Os serviços entram com nome, descrição e valor.
